# WFM 第三方品牌去除设计规格

**日期：** 2026-07-19

**状态：** 用户已确认书面设计规格，等待实施

**适用范围：** WFM 桌面 Web 的登录页、用户可见文案与仓库内可分发文档

## 1. 目标

对外演示界面不展示或暗示与本项目无授权关系的第三方品牌、租户、登录服务或技术产品。同时保留系统完整的登录能力、桌面布局和现有业务功能。

本次处理属于品牌去除和风险降低，不构成对任何商标、版权或授权状态的法律结论。

## 2. 登录页设计

- 删除表单上方的第三方品牌租户标签，不以其他虚构品牌替换。
- 删除整个右侧第三方企业身份登录面板，包括产品名、类似品牌图形符号、未接入说明和所属与授权暗示。
- 登录卡改为居中的单列桌面布局，保留系统名称、手机号、验证码、登录按钮与测试账号。
- 不新增“统一身份登录”或其他未接入功能的占位展示。
- 保留当前蓝青色背景和白色卡片视觉体系，不使用第三方 Logo、品牌色规范或图标资产。

## 3. 其他用户可见内容

- 将排班生成面板中的第三方优化引擎品牌名改为“智能排班”。
- 将导入失败等用户可见文案中的第三方办公产品名改为“表格文件（.xlsx）”。
- 保留 `.xlsx` 文件格式支持和原有导入功能；只改文案，不改变 API 协议与文件解析实现。
- 不更改服务端 provider 配置、环境变量、类名或依赖包名；这些是技术集成标识，不是顾客界面品牌展示。

## 4. 仓库文档与测试资料

- 将现行设计规格、实施计划、视觉检查清单和测试描述中的第三方零售品牌名、品牌操作手册文件名和绝对路径改为中性的“经授权的第三方视觉参考”或“旧版视觉参考”。
- 若文档更新影响已冻结的测试摘要或校验值，必须同步更新对应测试，不得绕过校验。
- 不删除仓库外的原始参考文件，不修改 Git 历史提交。若未来要公开整个仓库历史，需另行评估历史清理与授权证据。

## 5. 依赖许可与产品命名

- 本次代码变更不删除合法的开源依赖，不将依赖包名伪装成自有实现。
- 当前仓库未提供统一的第三方许可清单。这是对外交付前的合规待办，不等于已发生侵权。
- `WFM` 是行业常用缩写，但本次代码审计不能代替按实际商品或服务类别完成的商标检索。
- 依赖许可汇总文件、产品命名商标清查和 Git 历史重写均不在本次 UI 去品牌修复范围内，必须作为上线前独立合规任务跟踪。

## 6. 验收标准

1. 未登录访问根路由时，页面只有一列登录内容，不存在第三方租户或身份登录品牌。
2. 现有手机号、验证码登录与测试账号选择功能保持可用。
3. 页面可见文案不出现已识别的第三方运动品牌、云身份品牌、优化引擎品牌或办公产品品牌。
4. 仓库可分发文档不暴露第三方品牌手册文件名或本机绝对路径。
5. 新增测试先证明旧品牌内容仍存在或新布局尚未成立，再实施修复并跑到通过。
6. 完成单元测试、相关路由测试、静态搜索、桌面截图与外部分享链接复验。

## 7. 非目标

- 不引入新的租户系统、SSO 集成或登录方式。
- 不修改固定班次、门店权限、排班算法或数据库模型。
- 不处理手机端、APP 或原生桌面客户端。
- 不宣称通过法律审查或已获得任何第三方授权。
